# wintertt.github.io

HavenCast 的开发者网站，同时提供 Google AdMob 的 `app-ads.txt`。

- 站点地址：<https://wintertt.github.io/>
- `app-ads.txt` 必须放在域名根目录，不能放进子目录。
- AdMob 授权卖方记录：

```text
google.com, pub-8912539911574711, DIRECT, f08c47fec0942fa0
```

修改 `app-ads.txt` 后，在 AdMob 的「应用 → app-ads.txt → 检查是否有更新」中触发重新抓取。
